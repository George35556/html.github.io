Ce este CSS și Box Model?

CSS (Cascading Style Sheets) se ocupă de aspectul vizual al paginii. Fiecare element HTML este văzut de browser ca o cutie (Conceptul Box Model) compusă din:

  • Content: Conținutul propriu-zis (text, imagine);
  • Padding: Spațiul interior între conținut și bordură;
  • Border: Bordura din jurul elementului;
  • Margin: Spațiul exterior care separă elementul de alte elemente.
