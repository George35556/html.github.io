Ce este HTML?

HTML (HyperText Markup Language) este limbajul standard de marcare folosit pentru crearea paginilor web. El definește structura și conținutul unui document web.

Structura de bază a unui document HTML

Un fișier HTML conține câteva elemente esențiale pentru a fi recunoscut de browser:

  • <!DOCTYPE html> — declară versiunea de HTML (HTML5);
  • <html> — elementul rădăcină al paginii;
  • <head> — conține metadate (titlu, legături la stiluri CSS);
  • <body> — conține tot conținutul vizibil al paginii.
